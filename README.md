> **Zynk** adalah sebuah **Online Showcase Project/App** modern yang dirancang untuk menampilkan karya, portofolio, atau ide kreatif secara interaktif, cepat, dan terorganisir.
> Dibangun dengan perpaduan estetika glassmorphism dan kesederhanaan modern, Zynk cocok digunakan sebagai personal showcase maupun project hub.

---

## ✨ Fitur Utama 
- 📄 **Single Page Showcase**: Semua konten aplikasi ditampilkan dalam antarmuka terkurasi yang bersih dan responsif.
- 🎨 **Modern Glassmorphic UI/UX**: Desain estetis dengan mesh gradient, efek frosted glass, dan animasi yang halus.
- ⚡ **Lightweight & Fast**: Berjalan cepat dengan HTML5 & Tailwind CSS, tanpa framework yang memberatkan.
- 🔒 **Admin Area & Firebase Integration**: Kelola, tambah, dan edit portofolio secara real-time via Firebase Realtime Database.
- 🌍 **Easy Deployment**: Siap di-deploy secara instan di GitHub Pages, Vercel, Netlify, atau web server statis manapun.

## 🛠️ Cara Menjalankan
Buka file `index.html` langsung di browser, atau jalankan melalui live server lokal:

```bash
# Opsi 1: Menggunakan Python HTTP Server
python -m http.server 3000

# Opsi 2: Menggunakan npx serve
npx serve .
```

Akses di browser pada: `http://localhost:3000`
